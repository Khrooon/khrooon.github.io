# KHROOON — versión 5

Web estática preparada para GitHub Pages u otro alojamiento web.

## Publicación
Sube el **contenido** de esta carpeta (`index.html`, `styles.css`, `script.js` y `assets/`) a la raíz del repositorio o a la carpeta configurada para publicar.

## Cambios
- Portada: ordenador retro a la derecha y texto HTML legible a la izquierda.
- Khrooon 2.0: ilustración de castillo, distinta de la portada.
- Las lecciones de mamá: olla verde, ovillo y agujas de tejer.
- Soluciones a medida: pizarra matemática y lámpara fluorescente alargada con luz fría.
- Cine: imagen independiente.
- Mantiene el logotipo gráfico aprobado y las secciones de historia y contacto.
- Las imágenes se han recortado de la maqueta visual aprobada; su resolución es limitada en pantallas grandes.

No requiere dependencias ni servidor para abrir el HTML localmente.
